# Customer Behaviour Analysis

## Project Overview
This project analyses customer shopping behaviour to understand purchasing patterns, product preferences, customer reviews, discount usage, and shopping habits. The goal is to transform customer shopping data into meaningful insights that can help businesses understand their customers and make data-driven decisions.

**Project Status:** In Progress

## Objectives
- Analyse customer purchasing patterns and preferences.
- Identify popular products and highly rated items.
- Understand customer behaviour across different demographic groups.
- Explore discount usage and subscription patterns.
- Build an interactive dashboard to communicate business insights.

## Tools & Technologies
- **SQL Server:** Data exploration, aggregation, filtering, CTEs, subqueries, CASE expressions, and window functions.
- **Python:** Data analysis and exploration using pandas and Jupyter Notebook.
- **Power BI:** Interactive data visualisation and dashboard development.
- **Dataset:** Customer shopping behaviour dataset.

## Project Workflow
1. **Data Understanding:** Examined the dataset structure, columns, and data types.
2. **SQL Analysis:** Wrote queries to analyse purchasing patterns, product ratings, and customer segments.
3. **Python Analysis:** Used pandas to explore the dataset and investigate customer behaviour.
4. **Power BI Dashboard:** Developed visualisations to present key metrics and trends.
5. **Business Insights:** Identified findings and potential opportunities for improving customer engagement.

## Key Business Questions
- Which products are purchased most frequently?
- Which products have the highest average customer ratings?
- How do purchasing patterns vary across customer groups?
- How is discount usage related to purchase amounts?
- What differences exist between subscribed and non-subscribed customers?
- Which customer segments show repeat purchasing behaviour?
