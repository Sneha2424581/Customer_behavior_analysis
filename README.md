**Customer Behaviour Analysis | SQL Server, Python, Power BI**

- Analysed customer shopping data using SQL Server to identify purchasing patterns, product ratings, and customer segments.
- Used SQL aggregations, CASE expressions, CTEs, subqueries, and window functions to investigate customer and product behaviour.
- Used Python and pandas for data exploration and preparation.
- Developed an interactive Power BI dashboard to present customer, product, and purchasing insights.
